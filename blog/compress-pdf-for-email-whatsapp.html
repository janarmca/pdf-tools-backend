How to Compress a PDF for Email or WhatsApp Without Losing Quality

5 min read

Most email providers cap attachments around 25MB, and WhatsApp is stricter still. If a PDF won't go through, compressing it is almost always the fix — but done carelessly, it can turn crisp text into a blurry mess. Here's what's actually happening inside the file, and how to shrink it properly.

What makes a PDF large in the first place

It's rarely the text. A page of pure text, even a hundred pages, is usually only a few hundred KB. The weight almost always comes from:

  • Scanned pages saved as images — a scanner that saves each page as a high-resolution photo instead of proper text.
  • Uncompressed or oversized photos pasted into the document at full camera resolution when the page only displays them at a few inches wide.
  • Embedded fonts, especially if several different font families are used throughout.

The two approaches, and when to use which

1. Re-compress the images inside the PDF

This is the safe default. It reduces the resolution and file size of any embedded images while leaving actual text completely untouched — since text in a proper PDF is stored as text, not pixels, it stays perfectly sharp regardless of how much the images shrink.

2. Convert scanned pages with OCR

If your "PDF" is really a stack of scanned photos with no real text layer at all, compression alone won't get you very far — a scanned page is one giant image no matter how you slice it. Running OCR (text recognition) first turns those pages into actual searchable text, which is both dramatically smaller and far more useful (you can copy-paste from it, search it, and so on).

Tip: If a compressed file still looks too big, check whether it's mostly scanned pages. OCR-ing them first, then compressing, usually beats compression alone by a wide margin.

How much can you safely compress?

A reasonable compression pass typically cuts an image-heavy PDF by 40-70% with no visible quality loss on a screen or a normal printout. Going further starts to show — photos get soft edges, and small text inside scanned pages can blur. For something you're printing for legal or official use, keep compression moderate; for a quick WhatsApp share, more aggressive compression is usually fine.

Before you compress: check what's actually inside

Open the file and look at page 1. If it's crisp, selectable text — good, compression will barely touch it and mostly work on any images further in. If it looks like a photograph of a page, that's a scan, and OCR first will serve you better than compression alone.
