About this tool

If you forgot the password of a file that belongs to you, this tool tries commonly used passwords automatically. It only works for weak passwords and only on your own documents. Document Password Recovery is part of PDF Tools India's PDF toolkit. Forgot the password on your own PDF, Excel, or Word file? Try common/weak passwords automatically. Runs entirely in your browser — your file is never uploaded to a server. Available in Tamil and English, on both mobile and desktop, with no account required to try it.

How it works

  1. Open the tool and add your protected file.
  2. Start the automatic attempt.
  3. If a password is found it is shown so you can open the file.

Common uses

  • Old bank statements or payslips you protected yourself
  • Excel or Word files whose password you forgot
