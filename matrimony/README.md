## 1. கொள்கை (மாறாதது)
**எல்லாம் இலவசம்; AI பயன்படுத்தும் இடத்தில் மட்டும் கட்டணம்.**

| இலவசம் | கட்டணம் |
|---|---|
| பதிவு, குடும்ப விவரம், படங்கள், ஜாதகப் படம், பொதுப் பட்டியல் பார்த்தல், தொடர்பு கோரிக்கை, Interest, Chat (தற்போது) | AI ஜாதகம் → அடிப்படை விவரம் நிரப்பல்: 2 credits (`MATRIMONY_JATHAGAM_CREDITS`, 0 = இலவசம்; தோல்வியில் திரும்பக் கிடைக்கும்) |

எதிர்கால "package": Chat/தொடர்பு கட்டணம் இப்போது OFF. தொகை முடிவானதும் ON செய்ய (§8).

## 2. கட்டமைப்பு
* Frontend: `matrimony/` (vanilla JS SPA, hash routes). Cloudflare Pages `main`-ஐ தானாக deploy செய்கிறது.
* Backend: ஒரே Cloudflare Worker `https://pdftoolsindia.com/cfapi` (`cloudflare/src/mat.js`, `api.js`) + D1 + KV `MAT_PHOTOS` (படங்கள் ≤1.5MB). Supabase / Cloud Run **இல்லை**.
* Login: Google அல்லது email-க்கு வரும் 6 இலக்க code (`/cf-auth.js`). கடவுச்சொல் இல்லை.
* RPC: `POST /cfapi/mat/rpc/<name>`; உள்நுழையாதோர் அழைக்கக்கூடியவை `PUBLIC` தொகுப்பில் மட்டும்.
* Worker அமைப்பு/secrets: [`cloudflare/README.md`](../cloudflare/README.md). Migrations: `cloudflare/migrations/` ("Deploy Cloudflare API" workflow தானாக இயக்கும்; `0002_public_browse.sql` உட்பட).

## 3. பதிவு → admin → பொது (முழு ஓட்டம்)
1. **பதிவு (login தேவையில்லை):** முகப்பு → "இலவசமாகப் பதிவு செய்க" (`#/join`). விவரம், குடும்பம், படங்கள் (6 வரை), ஜாதகப் படம், மொபைல் எண். `mat_submissions`-ல் பதிவாகும். வரம்பு: ஒரு எண்ணுக்கு நாளுக்கு 3, மணிக்கு 300 மொத்தம்.
2. **Admin பார்வை:** நிர்வாகம் → *புதிய பதிவுகள்*: அனைத்து விவரம், படங்கள், ஜாதகம் (தட்டினால் பெரிதாகத் திறக்கும்; பதிவிறக்கி WhatsApp-ல் இருவீட்டாருக்கு அனுப்பலாம்), 📞 அழைப்பு, "தொடர்பு கொண்டேன் / முடிந்தது".
3. **அங்கீகாரம் → பொது:** "🌐 பொதுப் பட்டியலில் சேர்" அழுத்தினால் மட்டுமே `#/browse`-ல் அனைவருக்கும் (login இன்றி) தெரியும். "நீக்கு" மூலம் மறைக்கலாம்.
4. **தொடர்பு:** பார்ப்பவர் WhatsApp (99760 15722, சுயவிவர எண் குறிப்புடன்), அழைப்பு (தியாகராஜன் 96987 77639), email (support@pdftoolsindia.com) அல்லது "தொடர்பு கோரிக்கை" படிவம். கோரிக்கைகள் நிர்வாகம் → *தொடர்பு கோரிக்கைகள்*.
5. **திருமணம் முடிவு:** admin இரு குடும்பத்தையும் தொலைபேசியில் அழைத்து இறுதி செய்வார்.

### பொதுவில் தெரிவது / தெரியாதது
* தெரிவது (`PUBLIC_FIELDS`, `cloudflare/src/mat.js`): பெயர், வயது, பாலினம், உயரம், திருமண நிலை, மதம்/சமூகம், குலம், கோத்திரம், தாய்மொழி, நட்சத்திரம், ராசி, தோஷம், உணவு, கல்வி, தொழில், பெற்றோர் தொழில், உடன்பிறப்பு எண்ணிக்கை, குடும்ப வகை/நிலை, ஊர், மாநிலம், "பற்றி", எண் `SC-XXXXXX`.
* தெரியாதது: தொலைபேசி, email, பிறந்த தேதி, வருமானம், பெற்றோர் பெயர், சொந்த ஊர், குடும்பக் குறிப்பு, மாவட்டம், ஜாதகம். படங்கள்: அங்கீகரிக்கப்பட்ட உறுப்பினர்/admin-க்கு மட்டும்.
* தள உறுப்பினர் (கணக்கு) சுயவிவரங்கள் பொதுவில் காட்டப்படாது (அவர்கள் ஒப்புதல் உறுப்பினர்களுக்கு மட்டும்).

## 4. உறுப்பினர் பகுதி (கணக்குடன்)
தேடல், சுயவிவரம், Interest, விருப்பப்பட்டியல், தடு/புகார், Chat. அங்கீகரிக்கப்பட்ட, உள்நுழைந்தவர் மட்டுமே பிறர் சுயவிவரம் பார்க்கலாம். வரம்புகள்: நாளுக்கு 15 Interest, மணிக்கு 120 செய்திகள். திருமண வயது: ஆண் 21, பெண் 18.
Chat-ல் எண்/email/WhatsApp/link எந்த வடிவில் அனுப்பினாலும் server-ல் தடுக்கப்படும் (`m-filter.js` — frontend + Worker `contactCheck` ஒரே விதி). மீறல்: எச்சரிக்கை 1/3, 2/3, 3-வது முறை chat நிறுத்தம்; நிர்வாகம் → *புகார்கள்*-ல் மீட்டெடுக்கலாம். எந்த filter-ம் 100% அல்ல, அதனால் "புகார்" பொத்தான் + admin கண்காணிப்பு உள்ளது.

## 5. AI ஜாதகம் → அடிப்படை விவரம்
உள்நுழைந்தவர் பதிவு படிவத்தில் "ஜாதகம் பதிவேற்று" → Gemini படித்துப் பெயர், பாலினம், பிறந்த தேதி, நட்சத்திரம், ராசி நிரப்பும்; உறுப்பினர் திருத்தலாம். ஜாதகக் கோப்பு சேமிக்கப்படாது. தேவை: secret `GEMINI_API_KEY`; இல்லையெனில் "AI இன்னும் அமைக்கப்படவில்லை" என்று காட்டும், மற்றவை வேலை செய்யும். login இல்லாத பதிவில் AI இல்லை (ஜாதகப் படம் admin-க்கு மட்டும் செல்லும்).
