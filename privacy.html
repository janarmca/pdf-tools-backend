தனியுரிமைக் கொள்கை (Privacy Policy)

கடைசியாக புதுப்பிக்கப்பட்டது: ஆகஸ்ட் 2026
✅ உங்கள் கோப்புகள் (PDF/படம்/வீடியோ) — "Fast Server Mode" பயன்படுத்தாத வரை — உங்கள் browser-லேயே செயலாகும், எங்கள் சேவையகத்திற்கு அனுப்பப்படுவதில்லை.

1. நாங்கள் சேகரிக்கும் தகவல்

  • கணக்கு தகவல்: கணக்கு உருவாக்கும்போது மின்னஞ்சல் முகவரி.
  • பயன்பாட்டு தகவல்: எந்த கருவி பயன்படுத்தப்பட்டது, எத்தனை Credits செலவழிக்கப்பட்டது (கோப்பின் உள்ளடக்கம் அல்ல).
  • கோப்பு தகவல்: "Fast Server Mode" பயன்படுத்தும்போது மட்டும், உங்கள் கோப்பு தற்காலிகமாக எங்கள் சேவையகத்திற்கு அனுப்பப்பட்டு, செயலாக்கம் முடிந்தவுடன் உடனடியாக நிரந்தரமாக நீக்கப்படும். நாங்கள் அதை சேமிக்கவோ பார்க்கவோ மாட்டோம்.
  • கட்டண தகவல்: Razorpay மூலம் கட்டணம் செலுத்தும்போது, கார்டு/UPI விவரங்களை நாங்கள் சேமிப்பதில்லை — அது நேரடியாக Razorpay-ஆல் கையாளப்படுகிறது.

2. தகவலை எப்படி பயன்படுத்துகிறோம்

கணக்கு நிர்வாகம், Credits கணக்கீடு, மற்றும் சேவையை மேம்படுத்த மட்டுமே இந்த தகவல் பயன்படுத்தப்படும். உங்கள் தகவலை மூன்றாம் தரப்பினருக்கு விற்பனை செய்ய மாட்டோம்.

3. மூன்றாம் தரப்பு சேவைகள்

  • Supabase — கணக்கு/login மற்றும் தரவுத்தளத்திற்கு
  • Razorpay — கட்டண செயலாக்கத்திற்கு
  • Render — Fast Server Mode-க்கான சேவையகத்திற்கு

4. உங்கள் உரிமைகள்

உங்கள் கணக்கு தகவலை பார்க்க, திருத்த, அல்லது நீக்க கோர எங்களை தொடர்பு கொள்ளலாம்.

5. Cookies

Login session-ஐ நினைவில் வைக்க browser storage பயன்படுத்தப்படுகிறது. விளம்பர tracking cookies எதுவும் பயன்படுத்தப்படவில்லை.
